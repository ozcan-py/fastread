Tap the numbers 1 to 14 in order. They alternate between the left and right edge, so every step forces a full-width eye jump, the same fast, accurate saccades and return sweeps that reading depends on. Keep your head still; only the eyes move.

What works for reading
  1. Size and spacing beat typeface. 18–22 px text, line height 1.5–1.7 and 50–70 characters per line. Longer lines make the return sweep miss; shorter ones force too many stops.
  2. Dark text on a light page reads a little faster and with fewer errors in a lit room: the pupil is smaller, so the letters are sharper. Switch to Slate, Dark or Black when the room is dim and glare is the problem.
  3. Off-white beats pure white for long sessions (Paper, Cream, Sepia, Sage). Contrast is for sunlight on a phone or low vision.
  4. The font you know reads fastest. Tall-x-height sans faces (Inter, Lexend, Atkinson) stay clear at small sizes; Literata and Merriweather were drawn for screens and suit long texts.
  5. If letters swap or you lose the line (b/d, I/l): Atkinson Hyperlegible, 2–4 px word spacing and line height 1.7 or more.

Save scores to GitHub

Every finished drill is committed to a JSON file in a repository you own, so the same history shows up on every device you connect. This browser keeps only the connection below, plus a short queue if a save fails.

How to create the token
  1. Create a repository for the data, for example pace-data. Private is best; the file only holds your scores.
  2. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens and generate a new token.
  3. Repository access: Only select repositories, pick the data repository.
  4. Permissions: Contents, Read and write. Nothing else. Choose the longest expiry you are comfortable with.
  5. Paste the token above. It is stored only on this device, and a token scoped like this can touch nothing but that one repository.
